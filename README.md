# Pausa Bienestar

App web de bienestar emocional (prototipo MVP): registro de ánimo y síntomas, explicaciones, respiración guiada, meditación, ejercicios de TCC, guía "Brote", progreso y profesionales de ejemplo.

Es un único archivo `index.html` sin dependencias de build. Los datos se guardan solo en el navegador (localStorage).

Aviso: no reemplaza a un profesional de salud mental. Los perfiles de profesionales son ficticios y el chat usa respuestas armadas.
